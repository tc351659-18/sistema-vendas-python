# 🛒 Sistema de Vendas e Gestão de Estoque

Sistema desenvolvido em **Python** para auxiliar no controle de produtos, vendas, estoque e resultados financeiros de um pequeno negócio.

## 📊 Funcionalidades

* Cadastro de produtos
* Controle de estoque
* Registro de vendas
* Histórico de vendas
* Edição de vendas
* Exclusão de vendas
* Cálculo automático de faturamento
* Cálculo de custos
* Cálculo de lucro
* Controle de estoque mínimo
* Identificação de estoque baixo
* Dashboard financeiro
* Geração de relatórios em Excel
* Salvamento dos dados
* Registro de data e hora das vendas

## 💰 Dashboard financeiro

O sistema apresenta indicadores como:

* Faturamento
* Custos
* Lucro
* Itens vendidos
* Número de vendas
* Produtos cadastrados
* Produto mais vendido

## 🛠️ Tecnologias utilizadas

* Python
* Tkinter
* OpenPyXL
* Excel
* Automação de processos
* Análise de dados

## 🎯 Objetivo

O projeto foi desenvolvido com o objetivo de criar uma solução simples para gerenciamento de vendas e, ao mesmo tempo, aplicar conhecimentos de **programação, automação, organização de dados e análise financeira**.
